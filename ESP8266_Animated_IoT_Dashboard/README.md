# 📊 ESP8266 Animated IoT Dashboard

An interactive **IoT web dashboard** developed using the **ESP8266** to display sensor data through a dynamic and animated web interface.

The project demonstrates how an ESP8266 can host or communicate with a web-based dashboard to provide real-time monitoring of IoT data in an easy-to-understand visual format.

## 🔧 Components Used

* ESP8266 NodeMCU
* Sensors / IoT components used in the project
* Breadboard
* Jumper wires
* USB cable

## ⚙️ Features

* ESP8266-based IoT monitoring
* Web-based dashboard
* Animated user interface
* Real-time data visualization
* Wi-Fi connectivity
* Interactive monitoring interface

## 🛠️ Technologies Used

* **Microcontroller:** ESP8266 NodeMCU
* **Programming:** C/C++
* **IDE:** Arduino IDE
* **Communication:** Wi-Fi
* **Interface:** Web Dashboard
* **Frontend:** HTML, CSS, JavaScript

## 🔄 Working Principle

1. The ESP8266 connects to a Wi-Fi network.
2. Sensor or IoT data is collected by the system.
3. The collected data is processed by the ESP8266.
4. Data is displayed on the web-based dashboard.
5. Animated elements provide a visual representation of the real-time information.
6. The dashboard can be accessed through a web browser connected to the same network.
