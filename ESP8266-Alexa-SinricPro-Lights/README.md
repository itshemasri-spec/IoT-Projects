# 💡 ESP8266 Smart Light Control using Sinric Pro & Alexa

An IoT-based smart home automation project using an **ESP8266 NodeMCU**, **Sinric Pro**, and **Amazon Alexa** to control lights through voice commands.

The ESP8266 connects to Wi-Fi and communicates with the Sinric Pro cloud platform. Alexa voice commands are used to switch the connected light ON or OFF remotely.

## 🔄 Working Principle

1. The ESP8266 connects to a Wi-Fi network.
2. The ESP8266 establishes communication with Sinric Pro.
3. Sinric Pro connects the device with the Alexa ecosystem.
4. The user gives a voice command through Alexa.
5. The command is transmitted through the cloud to the ESP8266.
6. The ESP8266 controls the relay according to the received command.
7. The connected light is switched ON or OFF.

### Example Voice Commands

```text
"Alexa, turn on the light."
"Alexa, turn off the light."
```
