# 💡 ESP32 Matrix LED Control via Local IP Web Page

An IoT-based LED matrix control project using an **ESP32** and a local web interface.

The ESP32 connects to a Wi-Fi network and provides a web page that can be accessed through its local IP address. Users can control the connected LED matrix and display different patterns, characters, or messages through a web browser.

## 🔧 Components Used

* ESP32 Development Board
* LED Matrix Display
* Breadboard
* Jumper Wires
* USB Cable

## ⚙️ Features

* 💡 LED matrix control
* 🌐 Local web interface
* 📶 ESP32 Wi-Fi connectivity
* 🔗 IP-based browser access
* 📝 Display custom messages or patterns
* 🔄 Wireless control through a web browser

## 🛠️ Technologies Used

* **Microcontroller:** ESP32
* **Display:** LED Matrix
* **Programming:** C/C++
* **IDE:** Arduino IDE
* **Communication:** Wi-Fi
* **Interface:** HTML / CSS
* **Control:** Local Web Server

## 🔄 Working Principle

1. The ESP32 connects to the configured Wi-Fi network.
2. The ESP32 obtains a local IP address.
3. A web server is started on the ESP32.
4. The user enters the ESP32 IP address in a web browser.
5. The local web page provides controls for the LED matrix.
6. Commands received from the web page are processed by the ESP32.
7. The selected message or LED pattern is displayed on the matrix.

### Example

```text
ESP32 connected to Wi-Fi
IP Address: 192.168.1.105
Web server started
```

The user can access the control page using the displayed IP address.
